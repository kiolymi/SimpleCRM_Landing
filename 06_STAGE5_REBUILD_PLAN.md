# Simple CRM — карта полной пересборки этапа 5

## Зафиксированное фактическое состояние

- В живом Figma-файле исторически находятся 207 продуктовых экранов — 165 iPhone и 42 iPad, но текущая работа и итоговая приёмка охватывают только iPhone.
- Старые локальные счётчики 198 устарели и не являются источником истины.
- В прототипной секции основные фреймы имеют переход на весь экран и не имеют переходов на конкретных дочерних элементах.
- В продуктовых экранах найдено 1054 экземпляра компонентов, включая 85 полей, 42 tab bar и 16 системных overlays.
- Foundations документируют только Light-режим и содержат медицинские примеры, которые нужно заменить универсальными CRM-примерами.
- Существующие iPhone shell-компоненты требуют единой навигации и проверки активного раздела.
- Существующий компонент статусов визуально нестабилен и фактически не используется продуктом.

### Ограничение платформы

Целевая платформа — только актуальный iPhone в визуальном языке iOS 26. iPad, sidebar, master-detail и любые iPad-адаптации исключены из текущего объёма и критериев готовности. Существующие iPad-экраны сохраняются как исторический материал без дальнейшей доработки.

### Содержимое «Сегодня»

- ближайшая встреча и переход в детали;
- задачи на сегодня и просроченные задачи;
- непрочитанные сообщения;
- просроченные счета;
- новые запросы;
- компактные быстрые действия;
- контекстный системный плюс.

## Семантика управляющих элементов

| Действие | Trailing-элемент | Поведение |
|---|---|---|
| Текстовый ввод | Нет | Фокус и клавиатура |
| Короткий фиксированный выбор | Стрелки вверх/вниз или значение | Menu/picker |
| Большой список | Chevron right | Отдельный экран выбора |
| Дата/время | Иконка календаря/часов | Date/time picker |
| Включение | Switch | Немедленное изменение |
| Раскрытие | Chevron down | Раскрытие на месте |
| Внешняя ссылка | Arrow up-right | Выход во внешний контекст |
| Дополнительные действия | Ellipsis | Menu/action sheet |

Chevron right запрещён, если новый экран фактически не открывается.

## Система обратной связи

- Status row: постоянный факт внутри карточки или документа.
- Toast: краткий обратимый результат без блокировки.
- Inline feedback: ошибка или подсказка рядом с полем.
- Banner: важное состояние раздела, не требующее немедленного решения.
- Alert: критическое подтверждение или системное разрешение.
- Sheet: выбор, контекстные действия или подтверждение с дополнительными данными.
- Full-screen error: только когда пользователь не может продолжить работу.

## Итоги встречи

Редактирование:

1. Шаблон
2. Контекст
3. Результат
4. Следующие шаги
5. Дополнительные заметки

Каждый следующий шаг может стать задачей с исполнителем и сроком. Просмотр сохранённой записи отделён от режима редактирования.

## Основные продуктовые потоки

- Встреча: вход → создание → выбор клиента → дата/время → проверка → сохранение → детали → перенос/отмена → восстановление после ошибки.
- Клиент 360: список/поиск → обзор → активность → контакты → встречи → задачи → сообщения → документы → счета.
- Сообщения: входящие → поиск/получатель → диалог → вложение → отправка → success/failed/retry.
- Задачи: список → создание → приоритет → срок → исполнитель → сохранение → завершение/возврат/удаление.
- Документы: список → просмотр → действия → подписание → компактный статус → ошибка/retry.
- Платежи: счета → счёт → способ → подтверждение → processing → success/declined → чек.
- Глобальный поиск: клиенты, встречи, сообщения, задачи, документы и счета с фильтрацией по типу.

## Обязательные состояния

Default, loading, empty, no results, validation, offline, network error, disabled, keyboard-open, selected, processing, success, retry, permission, destructive confirmation и unsaved changes — только там, где состояние имеет продуктовый смысл.

## Критерий проверки экрана

Экран засчитывается только после фактического просмотра его отдельного рендера. Проверка координат, структуры или автоматических метрик используется лишь как дополнительный сигнал.
