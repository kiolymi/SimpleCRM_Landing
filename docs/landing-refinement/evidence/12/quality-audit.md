## Визуальный осмотр

- Mobile hero читается без обрезки: логотип, menu, заголовок, два CTA и пояснение помещаются в естественный вертикальный поток.
- Сценарий на мобильном сохраняет одну точку фокуса: роль → телефон → краткая подпись → шаги. Никакой hover-рамки не появляется.
- Автоматический progress тонкий и не конкурирует с содержанием; при pause замораживается.
- Фоновое видео заканчивается на границе hero, не удлиняется при hover телефона.
