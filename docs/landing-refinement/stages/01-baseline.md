# Этап 01 — Зафиксировать исходник и защитить прежнюю работу

## Режим запуска

Этот файл — инструкция только для одного этапа, не shell-скрипт.
Корень пакета: docs/landing-refinement/ в исходном репозитории SimpleCRM_Landing.
До действий прочитай README.md, COMMON.md, STATE.json, DECISIONS.md и ISSUES.md из корня пакета. Пути ниже относительны корню пакета.
При ручном запуске выполни только этот этап и остановись. При запуске через GOAL.md передай управление его последовательному циклу. Не запускай следующие этапы параллельно и не создавай другие задачи/агентов.
Это первый этап; состояние пакета prepared не означает, что baseline уже выполнен.

## Цель этапа

Создать проверяемую исходную точку для работы в новой ветке, не меняя лендинг.

## Входные материалы

- CONTEXT.md

## Что сделать

1. Проверь корень репозитория, origin, текущую ветку, HEAD, main и git status. Целевая ветка codex/landing-practice-refinement должна происходить от ae375a73e4eec2349167d191a773a76811cda97e. При несовпадении не переключай и не сбрасывай вслепую: установи причину.
2. Проверь AGENTS.md по пути и инструкции применимых skills. Учитывай незакоммиченные и неотслеживаемые пользовательские файлы. Не включай в работу чужие документы, транскрипции, модели и видеоэксперименты.
3. Запиши точные SHA main и gh-pages, рабочей ветки и состояние дерева. Не меняй main, gh-pages и настройки деплоя. Ветка сохраняет закоммиченную историю; незакоммиченные файлы не являются автоматически сохранёнными в Git.
4. Определи реальный способ локального запуска по README и проекту. Не выдумывай npm-команды, если package.json отсутствует. Не занимай чужой порт и не останавливай неизвестный процесс; при необходимости используй другой свободный порт.
5. Проверь главную, about, pricing, FAQ, learn и support. Сделай исходные скриншоты desktop/mobile. Зафиксируй видео, hover телефона, меню, основные переходы, ошибки и размеры hero до изменений.
6. Открой исходную Figma только для чтения, запиши file key и подходящие node IDs. Наметь отдельную рабочую страницу для будущих копий, не создавая полный редизайн сейчас.
