# Этап 06 — Подготовить тексты главной и общую терминологию

## Режим запуска

Этот файл — инструкция только для одного этапа, не shell-скрипт.
Корень пакета: docs/landing-refinement/ в исходном репозитории SimpleCRM_Landing.
До действий прочитай README.md, COMMON.md, STATE.json, DECISIONS.md и ISSUES.md из корня пакета. Пути ниже относительны корню пакета.
При ручном запуске выполни только этот этап и остановись. При запуске через GOAL.md передай управление его последовательному циклу. Не запускай следующие этапы параллельно и не создавай другие задачи/агентов.
Этап 05 должен иметь статус passed. Если обязательный результат отсутствует, вернись к нему; не подменяй его предположением.

## Цель этапа

Создать точные, короткие и естественные тексты с проверяемыми обещаниями.

## Входные материалы

- outputs/02-product-truth.md
- outputs/03-audience.md
- outputs/04-conversion.md
- outputs/05-structure.md

## Что сделать

1. Напиши готовые заголовки, пояснения, CTA, подписи, состояния примеров и финальный блок. Это рабочая редакция, не перечень общих советов.
2. Для каждого коммерческого/функционального утверждения укажи feature_id из реестра и допустимый статус. Неподтверждённые возможности вынеси в проектные примечания, не в уверенный публичный текст.
3. Проверь, что ясно, кто действует: специалист, клиент или система. Не выдавай ручное создание задачи за автоматическую отправку сообщения.
4. Прочитай страницу как последовательную историю. Убери повторные абстрактные обещания, лишние второстепенные заголовки и капслок-рубрики. Не сокращай существенные условия ради лаконичности.
5. Подготовь единый словарь: запись/встреча/занятие, подтверждение, оплата, предоплата, напоминание. Не используй один цвет или слово для разных состояний.
6. Подготовь редакционные изменения FAQ, pricing, about и support как список синхронизации для этапа 11. Проверь отсутствие недоказанных процентов, гарантий и социальных доказательств.

## Что сохранить

- outputs/06-copy.md

- Запись этапа в RUN_LOG.md, обновления ISSUES.md, DECISIONS.md и STATE.json.

- [ ] Есть готовые тексты, а не только рекомендации.
- [ ] Все обещания сопоставлены с источниками.
- [ ] Нет смысловых дублей и противоречивых терминов.
- [ ] Названия кнопок соответствуют действиям.
- [ ] Пройден локальный аудит этапа по COMMON.md; обязательные результаты не заменены обещанием.
- [ ] Отчёт содержит реальные доказательства и следующие действия, состояние сохранено.

Если переход невозможен, оставь этап needs_input или failed с точной причиной. Выполняй только независимые безопасные части этого же этапа. Не помечай зависимые этапы passed и не ослабляй критерии самостоятельно.
