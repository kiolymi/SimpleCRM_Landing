# Этап 09 — Подготовить изображения и осмысленную анимацию

## Режим запуска

Этот файл — инструкция только для одного этапа, не shell-скрипт.
Корень пакета: docs/landing-refinement/ в исходном репозитории SimpleCRM_Landing.
До действий прочитай README.md, COMMON.md, STATE.json, DECISIONS.md и ISSUES.md из корня пакета. Пути ниже относительны корню пакета.
При ручном запуске выполни только этот этап и остановись. При запуске через GOAL.md передай управление его последовательному циклу. Не запускай следующие этапы параллельно и не создавай другие задачи/агентов.
Этап 08 должен иметь статус passed. Если обязательный результат отсутствует, вернись к нему; не подменяй его предположением.

## Цель этапа

Добавить узнаваемые рабочие сцены и визуальные объяснения без декоративной перегрузки.

## Входные материалы

- outputs/05-structure.md
- outputs/06-copy.md
- outputs/08-figma.md
- outputs/08-figma-manifest.json

## Что сделать

1. Составь asset-план: роль изображения, место, формат, источник, что переиспользуем и что действительно отсутствует. Не генерируй изображения просто для заполнения блока.
2. Для генерации/редактирования используй подходящий imagegen skill и инструмент. Начни с одной приоритетной сцены, проверь стиль; затем переходи к следующей. Не запускай бесконечную массовую генерацию.
3. Сделай композиции различными: напоминание рядом со специалистом, крупный фрагмент записи и оплаты, два представления выбора времени. Люди помогают узнать ситуацию; экраны объясняют действие.
4. UI бери из Figma отдельным слоем, не генерируй точные интерфейсные надписи и фиктивные рабочие кнопки внутри фотографии. Не используй AI-людей как реальные отзывы клиентов.
5. Подготовь размеры для desktop/mobile, разумное сжатие, alt-тексты и резервные изображения. Сохрани происхождение и настройки экспорта без секретных временных URL.
6. Опиши motion-поведение: мягкий вход/выход, отдельный transform телефона, неизменный фон, отсутствие скачков layout, no-hover fallback и reduced-motion. Не удаляй клавиатурный focus ради просьбы убрать hover-рамку.
7. Существующее видео первого экрана не заменяй и не перекодируй без выявленной причины. Новые платные подписки/покупки/внешние публикации не разрешены.
